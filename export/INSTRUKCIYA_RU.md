# Выгрузка переписки Facebook-страницы

У инбокса Facebook-страницы нет кнопки «Скачать информацию». Сообщения можно
получить только через Graph API. Этот скрипт делает именно это.

В отличие от Instagram, здесь **не нужны ни App Review, ни верификация бизнеса** —
страница ваша, достаточно приложения в режиме разработки.

## Что нужно

- Python 3.8+ (на macOS уже установлен; для Windows — https://python.org)
- Аккаунт Facebook с правами **администратора** страницы

Дополнительные библиотеки не требуются.

## Шаги

### 1. Создать приложение Meta (один раз, ~5 минут)

1. https://developers.facebook.com/apps → **Create App**
2. Use case: **Other** → Type: **Business** → название (например `Chat Export`)
3. Больше ничего настраивать не нужно

### 2. Получить токен

1. Откройте https://developers.facebook.com/tools/explorer
2. Справа вверху выберите созданное приложение
3. **User or Page** → `User Token`
4. В **Add a Permission** отметьте:
   - `pages_show_list`
   - `pages_messaging`
   - `pages_read_engagement`
5. **Generate Access Token** → подтвердите доступ
6. Скопируйте длинную строку (токен)

> Токен действует ~1–2 часа. Для выгрузки этого достаточно.

### 3. Узнать токен страницы

```bash
python3 fb_messages_export.py --list-pages --token "ВАШ_USER_TOKEN"
```

Появится список страниц. Возьмите **ID** и **Token** нужной страницы.

### 4. Выгрузить сообщения

```bash
python3 fb_messages_export.py --page-id ID_СТРАНИЦЫ --token "ТОКЕН_СТРАНИЦЫ"
```

Результат — файл `messages_<id>_messenger.json` в этой же папке.

### Дополнительно

```bash
# 12 месяцев вместо 6
python3 fb_messages_export.py --page-id ID --token "..." --months 12
```

## Частые ошибки

| Ошибка | Причина |
|---|---|
| `Token muddati tugagan` | Токен истёк — повторите шаг 2 |
| `pages_messaging ruxsati yo'q` | На шаге 2 не отмечено разрешение |
| `Hech qanday suhbat topilmadi` | Нет переписок, либо использован User-токен вместо Page-токена |
| `(#200)` | Нет прав администратора страницы |

## Конфиденциальность

Файл содержит **личную переписку пациентов** — имена, телефоны, данные о здоровье.
Не выкладывайте его в общий доступ и удалите, когда он больше не нужен.
